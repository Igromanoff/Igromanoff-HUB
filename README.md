🔨 Igromanoff HUB — Бесплатный инструменты для настройки и восстановления Windows в одном месте Собрали в одном приложении функции, которые помогают исправлять неполадки, управлять параметрами системы и очищать накопитель.

☘️ Что умеет HUB:

🌐 Интернет и сеть — восстановление Wi-Fi, Bluetooth, сетевых служб, исправление проблем с подключением, VPN и прокси.

🎮 Игры и античиты — инструменты для решения проблем с запуском игр, FACEIT AC и другими античитами.

🔊 Устройства и звук — восстановление микрофона, аудиослужб, печати, сканеров и работы периферии.

🖥 Экран и графика — восстановление HDR, панели управления NVIDIA и настройка параметров изображения.

⚙️ Система и службы — проверка файлов Windows, восстановление компонентов и 47 карточек управления службами с пояснениями.

🔒 Приватность — управление разрешениями приложений, диагностическими данными и отдельными облачными функциями.

🧹 Очистка — поиск временных файлов, отчётов об ошибках, дампов и кэшей. Можно выбрать категории и посмотреть объём перед удалением.

🔄 Обновления HUB — проверка новых версий через GitHub, скачивание и установка по вашему нажатию.

☘️ HUB можно использовать самостоятельно, без установки плейбука. 
Для пользователей Igromanoff OS предусмотрен отдельный раздел с инструментами плейбука.

🧪 Сейчас HUB доступен в бета-версии. Обратная связь поможет сделать его лучше!

## Скачать

Откройте **[Releases](https://github.com/Igromanoff/Igromanoff-HUB/releases)** и выберите последнюю опубликованную версию.

- **`.msi`** — установка HUB и ярлыков, обновление установленной версии.
- **`.exe`** — переносимая версия без установки.
- **`SHA256SUMS.txt`** — контрольные суммы файлов.

Платформа: Windows x64. 
Поддержка: Только Windows 11

## Обновления

HUB проверяет GitHub Releases при запуске . 
Проверку можно отключить или запустить вручную кнопкой **«Обновления HUB»**.
