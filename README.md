# Igromanoff HUB

Инструменты для настройки и восстановления Windows, управления службами и очистки системы. HUB можно использовать самостоятельно или вместе с плейбуком Igromanoff OS.

## Скачать

Откройте **[Releases](https://github.com/Igromanoff/Igromanoff-HUB/releases)** и выберите последнюю опубликованную версию.

- **`.msi`** — установка HUB и ярлыков, обновление установленной версии.
- **`.exe`** — переносимая версия без установки.
- **`SHA256SUMS.txt`** — контрольные суммы файлов.

Платформа: Windows x64. Бета-выпуски отмечены как **Pre-release**.

## Обновления

HUB проверяет GitHub Releases при запуске . Проверку можно отключить или запустить вручную кнопкой **«Обновления HUB»**.
