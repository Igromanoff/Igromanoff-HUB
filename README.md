# Igromanoff HUB

Инструменты для настройки и восстановления Windows, управления службами и очистки системы. HUB можно использовать самостоятельно или вместе с плейбуком Igromanoff OS.

## Скачать

Откройте **[Releases](https://github.com/Igromanoff/Igromanoff-HUB/releases)** и выберите последнюю опубликованную версию.

- **`.msi`** — установка HUB и ярлыков, обновление установленной версии.
- **`.exe`** — переносимая версия без установки.
- **`SHA256SUMS.txt`** — контрольные суммы файлов.

Платформа: Windows x64. Бета-выпуски отмечены как **Pre-release**.

## Обновления

Начиная с версии **1.9.80**, HUB проверяет GitHub Releases при запуске не чаще раза в сутки. Проверку можно отключить или запустить вручную кнопкой **«Обновления HUB»**.

HUB показывает новую версию и описание изменений, скачивает установщик и проверяет его размер и SHA-256. Установка начинается только после нажатия **«Установить и закрыть HUB»**. Настройки приложения сохраняются. Во время работы инструмента HUB установка обновления недоступна.

При обновлении переносимой версии через MSI HUB устанавливается на компьютер; старый переносимый EXE остаётся на месте. Для сохранения переносимого режима скачайте новый EXE из Releases и замените им старый после закрытия HUB. Версии до 1.9.80 необходимо обновить вручную один раз.
